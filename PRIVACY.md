# Privacybeleid — Airfield Architect

*Laatst bijgewerkt: oktober 2026*

**Kort:** Airfield Architect verzamelt geen persoonsgegevens. Er zijn geen accounts, geen
advertenties, geen analytics en geen tracking.

- **Je spel blijft op je computer.** Opgeslagen spellen, instellingen, kaarten, mods,
  foto's en de ranglijst van de uitdagingen worden alleen op je eigen computer bewaard.
- **Cloudsaves (optioneel).** Zet je cloudsaves aan, dan schrijft het spel je saves in een
  map die jij kiest (bijvoorbeeld iCloud Drive). Het synchroniseren doet je
  besturingssysteem of je clouddienst; wij ontvangen niets.
- **Update-check (alleen de GitHub-versie, standaard uit).** Als je hem aanzet, vraagt het
  spel één keer per dag aan GitHub wat de nieuwste versie is. Daarbij wordt geen speldata
  of informatie over jou meegestuurd. De App Store-versie doet dit niet.
- **Foutrapporten.** Bij een crash bewaart het spel een rapport op je computer. Er wordt
  niets automatisch verstuurd; alleen als jij op "Fout melden" klikt, opent je browser een
  GitHub-pagina waar je het rapport zelf kunt plaatsen.

Vragen? Open een issue op https://github.com/rorymeijer/Airfield-Architect/issues.

# Privacy policy — Airfield Architect

**In short:** Airfield Architect collects no personal data. There are no accounts, no ads,
no analytics and no tracking.

- **Your game stays on your computer.** Saves, settings, maps, mods, photos and the
  challenge leaderboard are stored only on your own computer.
- **Cloud saves (optional).** If you turn them on, the game writes your saves to a folder
  you choose (for example iCloud Drive). Syncing is done by your operating system or cloud
  service; we receive nothing.
- **Update check (GitHub version only, off by default).** When on, the game asks GitHub
  once a day for the latest version, sending no game data or information about you. The
  App Store version doesn't do this.
- **Crash reports.** After a crash the game keeps a report on your computer. Nothing is
  sent automatically; only if you click "Report a bug" does your browser open a GitHub page
  where you can post it yourself.

Questions? Open an issue at https://github.com/rorymeijer/Airfield-Architect/issues.
